------------ Project Explanation ------------

This project is a pokemon-like game that allows you to pick a starter monster, catch, collect and battle approximately 50 monsters. There is a straight forward introduction to the game, however I would like to expand to create a more interactive mode of explaining how to play the game.

## How to Run the Project
1. install PHP on your computer
2. Place the project files inside a project folder
3. open a terminal in the project folder
4. start the PHP development server:
    php -S localhost:8000
5. Open a web browser and visit:
    http://localhost:8000/index.php
6. Create or select a game and begin playing

------------ Code Explanation ------------
Each game you create allows you to completely save all your data which includes gold, monsters, soul stones and potions. I also allowed for a auto healing logic once all the monsters are fainted. 

The Monsters are also randomly generated and I included three elemntal types that have damage multipliers and dampeners attached depending what monsters are battling. I would eventually like to have each monster have it's own set of moves and the ablity to unlock more powerfull moves for each monster much like how pokemon allows you to. 


------------ PHP Concepts Used ------------

The PHP concepts I used were multiple pages and states by using index.php etc. I also used user input becuase I allowed for the user to pick a new game, enter their player name, choose a new starter monster and use items along with buying those items and capturing monsters. Validatoin was also used because the my PHP code checks for missing save files and invalid sections as well as unavaliable items and invalid gold amounts. There are multiple conditonals using if, elseif and else for my game actions and outcomes. I also used foreach loops to display the current rosters, mosters, and saved game data. The functions.php file allowed me to have resuable functions for my save and loading logic as well as componants within my game machine. Monsters, player data, inventory, rosters, and game status was all was used within arrays. I also had sufficient file handling capabilities using JSON in the saves directory. My PHP ouput displayes gold, items, monsters and a bestiary with discoveries. Lastly I used a stylization within my CSS for navigation, background images, cards, soul stones and what I think is a nice presentation layer with thoughtful design.
